# gated-sandbox

Throwaway repository used as the live target for the end-to-end tests of [gated-github-mcp](https://github.com/EPW80/gated-github-mcp), an MCP server that lets an AI agent work with GitHub only within a policy file and records every call in a tamper-evident audit log.

Expect automated test activity here: comments on the open issues, CI runs, and a long-lived pull request into a throwaway branch (`e2e-merge-target`) that the test tries, and is expected to fail, to merge.

Nothing in this repository matters; it exists to be poked at.
